# Standard Fabric Server

## What is this ?

If you are looking for the right modpack for your new vanilla SMP or the starting point for a new modpack you are in the right place!

This modpack aims to make fabric server setup faster and easier by giving you all of the optimisation mods in 1 file.

### Useful information

- If needed, **there is a ZIP file** included in **[github releases](https://github.com/CubeBeveled/standard-fabric-server/releases)** with the mods
- If you **want ViaVersion** you can download & install [ViaVersion](https://modrinth.com/plugin/viaversion), [ViaBackwards](https://modrinth.com/plugin/viabackwards) & [ViaFabric](https://modrinth.com/mod/viafabric) for your server version. They are not included by default because they don't work on some versions
